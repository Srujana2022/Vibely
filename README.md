# Vibely

Vibely is a social media platform developed using HTML, CSS, JavaScript and Supabase.

## Features

- User registration and login
- User profiles
- Profile picture upload
- Text, image and video posts
- Likes and comments
- Follow and unfollow
- User search
- Direct messaging
- Notifications

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- Git
- GitHub
